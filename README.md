# Instituto Nacional Ernesto Flores

Sitio estático del INEF, elaborado con HTML, CSS y JavaScript. Puede abrirse
directamente como `index.html` o servirse con cualquier servidor web estático.

## Antes de publicar

- Confirmar el número de WhatsApp institucional antes de añadir un enlace directo
  al chat.
- Sustituir el horario pendiente en la sección de contacto por el horario oficial.
- Reemplazar las frases ilustrativas por testimonios reales con autorización.
- El formulario prepara una consulta en la aplicación de correo del visitante;
  no almacena ni envía datos a un servidor.

La galería usa las versiones WebP de `FOTOS/optimizadas/`; se conservan también
las fotografías originales en `FOTOS/`.
